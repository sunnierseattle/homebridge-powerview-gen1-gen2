Shade tools
Check reads a shade over radio, Jog wiggles it, Calibrate relearns its limits. More

Check asks the shade over radio where it really is. It takes a few seconds and briefly wakes the motor. Jog wiggles the shade to prove the radio and motor answer. Calibrate runs it fully up and down to relearn its limits, as the PowerView app does. It takes one to two minutes and must not be interrupted. Positions shown without a check are the hub's cached values.

These tools talk to the hub directly, so HomeKit does not hear about them straight away. A check also updates the position the hub keeps. HomeKit catches up the next time the plugin reads the hub: when the shade is next shown in the Home app, or on the next poll if pollShadesForUpdate is on. Each action is written to the Homebridge log.
